```
ACCEPTED (Task 3 candidate, fingerprint f6c79144…)
        ↓
Controlled one-character semantic regression introduced (>= → >)
        ↓
BLOCKED (blocked candidate, fingerprint d569d131…)
```

## 10. Known Limitations

1. **Behavioral equivalence is scoped to the defined executed corpus.** The contract covers 47 behavioral cases with 60 workflow steps. Cases outside this corpus are not evaluated.
2. **This is not formal program equivalence.** No formal verification, symbolic execution, or exhaustive proof was applied. The wording "behavioral equivalence demonstrated across the defined contract and executed scenario corpus" is used throughout and is accurate.
3. **The Bob clean-room contract is a finite scenario corpus.** Coverage is 96.65% statement / 91.67% branch — high but not 100%. Seven uncovered statements and eight uncovered branch arcs exist in the legacy source.
4. **Verifier quality depends on contract quality.** The contract was produced by three specialist subagent analyses of the legacy source. Source/policy discrepancies were identified and documented. The contract is not a formal specification.
5. **Task 4 had malformed output from two diagnostic subagents.**
   Subagents A (Counterexample Analyst) and C (Minimal Patch Risk Reviewer)
   returned malformed/garbled responses. Subagent B (Candidate Root-Cause
   Investigator) returned usable findings. The primary IBM Bob agent independently
   re-derived the affected diagnosis and risk-review findings from preserved
   evidence before applying the one-line repair. Unanimous multi-agent agreement
   is not claimed.
6. **Task 5 had malformed output from one review subagent.** Subagent B (Workflow Provenance Auditor) returned garbled output. Provenance was audited by direct file inspection.
7. **The demo domain is a controlled billing system.** The legacy application (`legacy_app/billing/monolith.py`) is a purpose-built demo for this run. No claim is made for applicability to production systems.
8. **No claim is made for unseen behavior outside the executed contract.** Behavior at untested inputs, floating-point sub-cent boundaries, concurrent access, or non-integer hour values is not covered by this evidence.
9. **Bobcoin values are supported by captured IBM Bob task-session UI evidence and are not recomputed by Aegis.** No Bobcoin values are stored in workspace artifacts; they cannot be independently verified from this workspace alone.
